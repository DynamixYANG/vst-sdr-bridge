# Vst.Hub

Windows application: MonitorForm supplies independent RX/TX header badges, uncluttered monitors and chronological Logs & Debug. ConfigurationControls shares editable numeric dropdowns, suggested values and option-specific hover tips between RX/TX. BridgeMonitor owns application executable paths, arguments and launch actions. TxMonitor configures TDMS/CS16 playback and saves queue/FIFO/prefill defaults for live clients. AppFiles stores settings, installs the embedded Soapy module and launches applications without a shell. Program supplies CLI/render-check/self-test modes; SelfTests validates transport/control behavior.

MonitorForm.BuildFooter owns permanent RX/TX Start/Stop actions outside the tabs. DarkChoice owner-draws recommendation lists and dark arrow buttons; NumberChoice adds numeric validation.
