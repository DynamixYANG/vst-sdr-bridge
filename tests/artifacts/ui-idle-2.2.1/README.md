# Configuration field review

Twelve actual WinForms DrawToBitmap renders and layout records cover six tabs at default/minimum dimensions (144 DPI), before hardware regression starts. RX/TX configuration pages at both sizes were visually inspected: dark white-text fields, no inactive blue selection, both status badges stopped, permanent footer buttons. Visible numeric fields have SelectionLength=0. Hidden controls are excluded from the selection probe. This records widget rendering, not automated desktop clicking.
