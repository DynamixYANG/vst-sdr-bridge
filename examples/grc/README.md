# Golden GNU Radio duplex example

GNU Radio reference flowgraph at 120 MS/s in both directions. Open vst_bridge_120_duplex.grc in GNU Radio Companion and run. vst_bridge_120_duplex.py is generated by grcc and is directly runnable in the radioconda environment.

The TX source repeats a precomputed 120-sample +1 MHz tone in a long vector. It avoids real-time oscillator CPU cost on the tested i7-6700. The source output buffer holds at least 1,048,576 complex samples; Soapy TX converts CF32 into the Hub CS16 ring. RX feeds an actual Qt spectrum and waterfall without sample-rate decimation.

Settings: TX/RX center 2500 MHz, TX peak −10 dBm, RX reference −20 dBm, RF enabled explicitly in the Soapy Sink settings. RF OUT and RF IN use the operator's adjacent antennas. Stop the flowgraph or send TXSTOP to turn RF off. RF-off transport use: change both rf_enabled=true settings in the sink to false.

Only one RX consumer: disable GQRX DSP before running this duplex example. The generated source must not be hand-edited; change the .grc and regenerate with scripts/Launch-Example.ps1. Golden status and screenshots: ../../docs/VALIDATION.md.

The .grc includes a main-after-init snippet that sets both TX source and sink min/max scheduler work size to 262,144 and thread priority to 1. Preserve this snippet. Final hardware run: 1,200.718 seconds; RX delivery 120.039 MS/s, TX processing 119.992 MS/s, zero loss/underflow. See [validation](../../docs/VALIDATION.md).
