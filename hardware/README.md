# Hardware assets

`ni-pxie-5644r/` records the exact NI Streaming for VST FPGA design used by this adapter, its origin, hash and original NI Sample Code license. `ni-pxie-5644r/local/` contains the imported vendor bitfile on the local machine; its binary is excluded from Git and public packages.

Run `scripts/Import-NiBitfile.ps1` after installing the matching NI example. See [requirements](../docs/REQUIREMENTS.md). NI drivers and runtime DLLs remain installed external software.
