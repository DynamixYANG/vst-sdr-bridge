# gr-vst

Optional Python GNU Radio package. tx_sink/tx_ring/hub_control connect to the Hub TX ring. The pure-Python sink is a prototype and is not the recommended sustained 120 MS/s path; use native Soapy Sink. rfsa_source/nirfsa_ctypes are legacy direct-Fetch RX and must not run alongside the Hub hardware owner. See README.TX.md and ../examples/grc.
